## 编号与维护

阶段目录采用`NN_主题`，research、plan、record和archive使用同一个阶段号。00是此前工作统一归档号，不重新虚构早期多个正式阶段；01是本次重新编号的起点。以后确实进入新阶段时才建立02，不按每次聊天或每个小修复增加阶段号，也不预建空目录。

阶段内部先维护README和一份issues清单；专题确实需要脚本、图表或多份研究时，再按`01_主题`、`02_主题`创建子目录。新阶段不会复制全部现行plan或数据。归档只搬移已有依据，保持原日期/结论和结果内容；改正相对链接或脚本路径时在record中说明。
