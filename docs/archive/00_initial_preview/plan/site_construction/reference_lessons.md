## 1. 资料覆盖范围

- CATvariant：主要为FBN1首轮页面、交互及接口观察；该样例没有可用结构，不能据此认定其全站结构实现。
- ProtVar：变异表格、isoform、部分注释与结构模型切换/定位已调研；小屏、部分下载和口袋/互作仍有未验证项。
- PTMD：有用户截图及人体组织图研究目标，线上专项尚未完成，不能作为现成实现方案。
- 包内SVG、CSS、HTML及React示例不等于完整产品；合成契约不是科研数据，候选工具不等于已安装或已集成。原站后端框架与数据库不能由页面观测推定。

## 2. 经验如何应用于memVar

| 经验 | 项目采用方式 | 理由与限制 |
| --- | --- | --- |
| CATvariant：按研究问题提供多个入口 | 当前以蛋白为入口，页内序列、结构、变异、疾病等板块共用实体与来源证据 | 避免同一对象在不同入口出现不同事实；不为入口复制数据 |
| ProtVar：明确一对多蛋白/isoform对应 | 保留条目归属与实际注释对象、序列和位置 | 不照搬其canonical主行作为本项目代表后果规则；MANE与canonical不自动等同 |
| 共同位置支持跨视图探索 | 序列、结构和位点共享已确认映射 | 模型、链、插入码及缺失残基必须明确，结构viewer不负责解决科学映射 |
| 摘要与详情可相互追溯 | GO slim等派生分类可以回到具体注释、对象和证据 | 分类不是新增实验支持；不同计数实体分别定义 |
| 多入口共用详情 | API统一身份与证据返回，前端复用详情逻辑 | 切换入口仍保持同一数据版本及对象 |
| 查询可复现 | URL保存对象和筛选，列表与导出共用查询逻辑 | 当前不承诺历史Web快照可恢复，版本变化需明确表达 |
| 内容分层 | 初版分别落实数据库、API和页面信息，以简洁主表、类别筛选和展开详情组织已选内容 | 展示精简不删除来源事实；字段取舍由自主构建授权落实，不冒称Basic info选择题已逐项确认 |

## 3. 不直接照搬的做法

- 页面与API计数差异是报告中的有限观察，原因未证实。memVar应明确统计实体和筛选口径，各入口统一查询，不能复制各算一份总数的方式。
- 报告记录了频率默认值的代码分支线索，但未逐条回放全部记录。项目明确缺失频率不进入数值分箱，不为图形填充虚构值。
- 预测分数、来源临床分类、审核状态及实验支持保留不同含义，不合并为无出处的统一可信度。
- 基因关联不等于变异证据或isoform特异结论；重复来源不自动计为独立实验。
- 原站外观、动画与图标不决定本项目数据模型。初版主要借鉴CATvariant和ProtVar的信息层次，并参考optional公共UI方向采用有限强调色、表格与展开内容；没有整体照搬某个候选方向，也不据此推定或照搬原站后端。

## 4. 素材采用边界

已有素材用于理解信息组织与视觉取舍，实际采用素材时按所选文件保留来源和许可。研究截图、DOM及接口快照不直接作为产品资源；不用参考包的校验模板扩展本项目QC，也不计算SHA-256。初版已按组件实际能力接入所需依赖；后续升级继续核对版本与能力，不增加无关组件或环境。
