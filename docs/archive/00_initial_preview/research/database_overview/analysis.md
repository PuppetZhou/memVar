## 参考与采用

Results以分析任务总量、注释覆盖、类别过滤和逐基因卡片组织入口。memVar是预构建数据库，采用统计摘要→按数据关系选择图形→现有蛋白检索，不迁移任务提交、私有分析等不存在的功能。Documentation采用介绍→能力/流程→解读的顺序；memVar压缩为介绍、使用指南、纳入与证据口径、来源/版本和实际API。未移植CATVariant热点阈值、优先评分及临床计算方法。

样式借鉴白底卡片、彩色图标与关键数值，图条保留单位/完整计数，文字不靠浅色降低对比。膜类型采用各自同分母的覆盖率圆环，多来源成员采用纵向比较柱图；只有互斥字段类别或分别存储的来源记录组成采用环图，避免将重叠对象误画为互斥分区。

## 审查额外发现

1. 唯一变异与transcript注释数量不同；来源成员、consequence术语重叠，不能相加。
2. 预测字段多于工具；PolyPhen HDIV/HVAR等是配置标签，不能把字段数称作独立算法或独立证据数。
3. 日期式处理snapshot不是数据库release；ThermoMPNN处理run不能冒充模型版本。
4. 来源登记不是纳入集合。膜来源关联也不代表其位点已映射canonical。
5. 既有inputs配置中的频率阶段说明曾落后于实际已导入manifest；以验证过的当前发布产物核对，修正过时说明，不重跑科学流程。
6. API示例需链接服务器端`/docs`而非由SPA路由处理；文档来源文字在API暂不可用时仍可读。

## 用户后续图形反馈与修正

- **问题**：所有板块都逐条横向条形，层次单一。**处理**：覆盖率圆环、组成环图、纵向柱图、分组标签库和场景数据集卡混合呈现，当前对照表维护于方案。
- **问题**：长来源/工具清单未归类。**处理**：膜来源分目录家族，consequence分术语家族，工具按输出字段数量分组并可搜索，Expression按实际数据集场景切换。
- **额外发现**：膜标签合计7,753大于7,715蛋白；变异来源/后果同样重叠。不得把其行和当唯一实体总量，原统计口径不变。
- **环图适用性核对**：生成器将每个评分字段分到一个组/关联层次；疾病按每条evidence所属dataset来源统计且校验总和；QTL按三个来源表行数统计。只在这些相应记录/字段层次表达组成。
- **完整性**：12个膜来源和13个Expression集合在新分组中各出现一次；未知标签保留Other。FANTOM/CAGE、DVP/MS沿用已有ContextDisplay的数据集方法对应关系。
- **验证限制**：侧会话Browser无连接，真实交互与移动端截图待补；静态React渲染发现SVG title多children警告，已改为单字符串并复验无警告。
