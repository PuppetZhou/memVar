## 3. 最重要的边界

### 3.1 位点属性与替换效应

同一个sequence位置可以关联多个不同氨基酸替换。JSD、已观察PTM及膜区段描述参考位置的背景；ddG描述某次替换在指定模型/结构下的预测。因此JSD归位点层，ddG归变异效应层；二者可以在同一位置详情中一起查询，但不能合并成“一位点一分数”。

序列轨道同时容纳单残基、区间、配对端点与残基集合，不能将二硫键两个端点自动显示为整段注释。结构视图是读取这些对象的展示方式，不必单独成为第五个科学板块。

位点有PTM注释不证明任一替换会破坏该PTM；预测落在界面也不证明该替换改变结合。此类结论需要对应变异证据或另行确认的科学方法。

### 3.2 基因组变异与蛋白后果

当前variant同时包含错义、同义等允许后果；不能把“突变”统一解释为氨基酸替换。推荐栏目名称使用“变异与效应”，详情明确对象。同一个DNA变异可有多个后果；不同DNA变异也可能产生相同蛋白替换。

频率和AVI/剪接等变异级评分保持variant身份，不能因蛋白替换相同而直接合并；转录本级评分保留所选参考上下文。HGVSp存在不证明已经匹配当前UniProt序列。基因相关变异可以列出，只有已验证坐标关系才能标记到具体序列轨道；未完成该关系的记录保留状态。

### 3.3 疾病背景与具体变异疾病证据

疾病栏目内部区分基因—疾病、变异—疾病、疾病—表型三个对象关系。由蛋白到基因疾病背景导航是可用查询，但不能把一条基因疾病关系赋给该蛋白所有变异。

ClinVar临床分类可以在变异列表显示已有来源字段；疾病详情中的具体条件/断言关联仍需相应整理，不将总体标签复制给每个疾病。推荐以同一证据关系支持两个入口，避免网页各自生成不同结论。[当前疾病契约](../../../../../../modules/disease/docs/tables.md)。

### 3.4 QTL、PPI及定位跨板块使用

- QTL可以放在蛋白背景下的“表达与调控关联”，底层仍保留变异、目标分子表型、组织和研究背景。只有组装/坐标/等位基因等关联可靠时，才在具体variant页复用；现有基因身份mapping不等于完成了variant_id关联。不能默认将QTL限制到当前编码SNV集合，否则改变既定来源范围；也不能把关联等同因果。
- PPI在背景层回答与谁关联；site层界面回答哪些残基在什么结构或伙伴条件下有接触/预测。伙伴特异结果不压成一个无条件的通用界面标签。IntAct mutation属于变异功能效应候选，仍依赖构建体/坐标核对。
- 细胞定位是蛋白背景；跨膜区段、膜侧别或逐残基脂质接触属于位点/区域环境。两者可联动，不互相替代。
- Rhea反应、GtoPdb靶点/配体已在现有数据中，可作为功能背景的子项审查，不必另开一级栏目。具体分子结合位点若有可靠位置证据，可由site层导航。

## 5. 推荐查询路径与后续统计

推荐蛋白页包含简短概览与明确序列选择，以及四板块入口。用户可直接打开变异详情或位点详情，两个视角相互导航：蛋白 → 明确序列 → 位点/区域 → 此处已映射变异 → 对应效应和疾病证据。该路径仅表示查询关系，不表示生物学因果，基因疾病与表达/QTL背景不强制经过site。

最有价值的下一步统计是“一个蛋白条目能可靠串起多少数据”，而非再次累加全库行数：

1. 蛋白级覆盖：每个板块按项目7,715蛋白报告可关联范围；仅TM专题另注明5,214分母。不同关联层次单独计数。
2. 变异可定位性：唯一variant、代表后果、已验证sequence位置三种分母分别统计，区分未处理、无可用参考、歧义和不适用；复用既有mapping，未建关系不在Web层猜配。
3. 位点注释重叠：在同一明确序列上比较膜区段、PTM、功能位点、JSD和已定位变异的交集，区分唯一位点和来源记录。
4. 字段审查：逐类核对含义、单位、空值及常用性，提出数据库保留、API返回、页面概览/详情方案；不因空值较多直接删除字段。
5. 代表实例：选择注释丰富、注释稀疏、存在isoform差异和存在未定位记录的蛋白，验证四板块能否准确联动；具体样本在专题统计时选定。
