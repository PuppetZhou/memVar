# 膜关联特征：蛋白概览、序列与位点的分工

> 00阶段历史研究，2026-09-22归档。保留当时依据与状态；当前任务、规则和交付入口见[归档说明](../../README.md)，本文不作为当前执行指令。

日期：2026-09-20。五类膜标签词表已确认，其判定规则及本页的概览字段、统计口径仍为建议。没有新增打标、合并区间、构建表或运行预测。

## 一、推荐的层次

| 层次 | 对象与内容 | 放置建议 |
| --- | --- | --- |
| 蛋白条目 | 项目收录依据、来源给出的膜关联方式、原生对象范围及来源链接 | 概览默认展示 |
| 具体序列 | canonical/isoform的跨膜区段数、α螺旋/β桶等来源类型、信号肽标志、膜内区段数、可用注释状态 | 少量序列摘要可出现在概览，但明确sequence_id与来源，详情在sequence |
| 区段与残基 | TM/Intramembrane/拓扑侧别区间、锚定位点、信号肽切割位点、位置级预测 | sequence轨道与site查询 |
| 结构/模拟观察 | 膜接触残基、深度/距离、伙伴或脂质接触、具体结构朝向与模拟量 | 带PDB/链/模型/模拟背景的详情；映射确认后才关联site |

概览显示不改变数据粒度。“跨膜区段数”本质是序列×来源/方法的统计，不能保存为无来源的蛋白永久属性。条目标签若由特定isoform或加工产物支持，须显示其范围，不能用其结果反向标成canonical属性。

## 二、蛋白概览建议保留什么

1. 收录依据：当前目标来自人类reviewed UniProt膜关键词查询，保存来源与版本，不把收录本身称实验确认跨膜。
2. 膜关联标签：跨膜、脂质锚定、外周膜蛋白、膜内嵌入、膜相关（不明确），允许带对象范围并存；保留原始来源术语与证据。
3. 可选的来源描述：single-pass/multi-pass、明确脂锚类型等；只在来源支持时呈现。具体坐标在下级视图。
4. 注释入口/覆盖状态：有UniProt区段、外部已定位区段、预测结果或结构/模拟背景，点击进入相应详情。来源可用不等于位置映射成功，也不计成独立证据数量。

不在这里重复细胞定位表，不从所有脂化事件自动推出脂锚，不用“没有跨膜区段”推出外周膜蛋白，不将不同来源多数票作为膜类别。

## 三、可以显示但需标出序列与来源的统计

建议首期只保留当前序列跨膜区段数、膜内区段数，辅以来源与详情入口。未来若用户需要再加入膜区段残基覆盖量/比例、脂锚位点数或跨isoform差异。

跨膜区段计数必须限定来源及feature类型，不能将UniProt、HTP、CCTOP和预测区间相加。展示基线可优先研究UniProt当前序列feature，DeepTMHMM2独立标“预测”，不是覆盖UniProt。单来源内部重复/重叠与边界不确定记录须按后续计数契约处理。覆盖比例只有明确采用该序列、该来源区间并集并除以该序列长度时才有可解释含义，本轮未确认或计算。

没有可用映射、来源缺失、真实零和不适用分别表达。不能因source entry有信息但canonical没匹配就填0。不同isoform的序列差异不自动等同已证实的定位改变。

## 四、现有数据支撑和实际边界

### UniProt现状

本专题2026-09-20已完成来源存在性统计，复用[summary.json](results/summary.json)：

| 内容存在性 | 条目数 |
| --- | ---: |
| Transmembrane feature | 5,214 |
| 明确Lipid-anchor topology | 473 |
| 明确Peripheral membrane protein topology | 1,067 |
| Intramembrane feature | 238 |
| Lipidation feature | 702 |

这些是accession层的来源存在性，不是互斥分类数或canonical序列计数；molecule范围尚未在该统计中解析。702条目有脂化不等于702个脂锚蛋白。不得把五类计数直接相加。

### 已发布外部定位数据

membrane四张正式表保留sequence_check、identity_link、feature_location和domain_feature_link。当前首批接受明确对象的唯一完整序列exact，不能把身份桥当坐标映射。2,115,852条位置混合了来源综合结果、预测和约束，不是独立TM区段或实验数。TM分母5,214中5,016有至少一条外部已定位区间；该口径不是所有7,715条目的定位率。

HTP/CCTOP/TmAlphaFold、TOPDB、PDBTM等适合sequence的分来源轨道，TOPDOM约束不是本项目新跑的domain搜索。AFTM假定结构参考试映射仍是trial，不混入正式计数。

### DeepTMHMM2

16,655条可获取序列预测全部完成并通过结果完整性核对：7,715 canonical、8,940非canonical。79条不可获取isoform声明单独保留。输出有序列类型、TM螺旋数、β桶链数、SP/TP标志、膜类型及概率、区段和逐残基拓扑。仍在runs，尚未发布curated，不能直接宣称可用于正式Web。

适合在概览保留带“预测”标识的序列摘要，完整区段/逐残基拓扑进入sequence/site。原始概率留详情，不能命名成“膜蛋白总体可信度”或“拓扑准确率”。预测Globular不是自动剔除现有膜相关条目的依据。

### 脂质接触、结构与模拟

MemProtMD已采集2,892个模拟context，2,847份contacts可用，关联793个蛋白至少有contacts文件；不等于目标残基已映射。MPLID/BioDolphin/旧OPM等保留来源记录，结构编号、位点映射或旧共识仍有待处理项。概览可研究来源存在性入口，不能据此生成“脂质结合位点总数”或跨结构平均深度。

上述状态依据[membrane结果](../../../../../../modules/membrane/docs/result.md)与[现行规则](../../../../../../modules/membrane/docs/rules.md)，本轮仅阅读，不重复全量核对。
