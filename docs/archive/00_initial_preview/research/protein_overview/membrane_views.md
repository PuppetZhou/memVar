## 推荐结构

在蛋白详情内设置“膜特征”区域，内含四个可展开视图：多来源拓扑、DeepTMHMM2预测、OPM膜取向、膜接触。上方仍是精简的UniProt膜关联说明。不是四个互不相干的新蛋白页面，也不为每个视图复制序列和位点数据。

这些视图与通用sequence视图共用序列选择器、1-based闭区间、位点选择和已确认映射。默认canonical，其他isoform可切换，来源没有该isoform匹配时提示缺失而不回退套用canonical轨道。

| 展示区 | 默认内容 | 展开或点击 |
| --- | --- | --- |
| UniProt膜关联说明 | 来源膜关联术语、脂锚类型等；对象标记 | 源证据、明确位点及对应序列；其他isoform折叠 |
| 多来源TOPO | 同一序列下各来源的最终/综合拓扑轨道 | 起止、类型、侧别、来源方法、文献、来源约束及分方法预测 |
| DeepTMHMM2 | 预测类型、拓扑轨道及区段摘要 | 膜类型概率、区段/逐残基拓扑、模型来源与状态 |
| OPM | 选中结构的膜位置与取向 | 结构/链、膜平面及该结构的几何或来源描述，按实际字段能力展示 |
| 膜接触 | MPLID及BioDolphin分来源记录 | PDB/链、配体实例、接触或结合位点、来源参数与已验证的序列对应 |

OPM是否直接采用3D视图需看可用结构与变换信息；当前旧site summary不能自动充当已验收的新3D取向数据。先按真实数据能力设计，不承诺已有字段足以复现源站。

## TOPO为何看起来杂乱

必须分开三件事：获取数据库/文件、注释产生方法、记录作用（最终拓扑/分方法预测/约束/结构推断）。数据库不是证据等级；同一方法被不同数据库转引也不是独立支持。

| 来源入口 | 推荐组织 | 不应混淆 |
| --- | --- | --- |
| UniProt | 注释轨道：TM、Intramembrane及来源拓扑区段 | 脂锚点可链接概览；不再复制亚定位说明 |
| HTP | 来源最终拓扑为主轨道，分方法预测和约束折叠 | 全量与3D/experimental benchmark可能重叠，不计三票；文件名不是每条记录的证据类型 |
| TOPDB | 来源最终拓扑为主轨道，证据区间/约束展开 | 不是所有区间都等于直接实验验证的跨膜区段 |
| TmAlphaFold | 分成CCTOP和TmDet子轨道 | CCTOP方法和TmAlphaFold来源不是同一维度，二者不合成一个区段集合；TmDet为结构几何推断背景 |
| TOPDOM | 放在来源约束详情中，按已定位domain_feature_link查询 | 模型侧别不是具体蛋白坐标，不作为另一条独立全长拓扑 |
| PDBTM（候选） | 若保留，放结构来源的TOPO可选组，按PDB/链区分 | 用户此次没有确定位置，不静默删除；不同结构观察不平均 |

建议首屏按来源分行并附方法/证据性质标签，结构来源折叠。不要称该区域全部都是实验拓扑：这里包含来源注释、综合推断和预测；与单独DeepTMHMM2视图区别在于来源组织，并非“实验对预测”二分。

AFTM与MemProtMD不进入当前TOPO。AFTM的数据库转引不反向补进轨道；原独立来源仍可用。MemProtMD本轮不另设默认卡片，其未来是否纳入膜接触留待明确需求。

## 哪些放通用sequence，哪些单开

通用sequence首屏负责序列与常用注释入口，可保留一条UniProt膜区段基线和已确认脂锚点，同屏还可有domain/PTM/变异等。全部拓扑来源不默认铺满通用sequence，进入TOPO后完整比较。

- 跨膜/膜内区段：完整细节在TOPO；sequence可显示基线或用户选中的同一条轨道，不复制数据。
- 脂锚类型及位点：概览直接显示，如“来源脂锚类型；sequence_id；位点”；点击在sequence定位。源位点不确定时保留范围/未知，不猜单点。
- 单点证据：site页按当前序列和位置聚合TOPO、预测、OPM及接触来源；不是再次存储一套注释。
- 结构几何与接触：OPM和接触视图独立提供结构上下文；映射已验证的残基可联动sequence，未映射则保留PDB链原编号和状态。

sequence与TOPO共用同一个序列对象和可复用轨道组件即可，不需要因单开视图而增加多个序列主表。页面分区也不等于一分区一张数据库表；服务表数量在记录粒度和映射确定后设计。

## 蛋白层面剩余信息与可选统计

默认保留来源膜关联标签、明确脂锚类别及位点、对象与证据入口。位置已在定位板块，长区段列表放TOPO。

跨膜区段数按所选sequence及单独来源显示，可放对应轨道旁，不建议概览用一个混合总数。DeepTMHMM2螺旋数/β链数在预测区独立标明。OPM结构数量与接触来源结构/配体数量若需展示，必须按明确实体去重，不能把来源残基行数作为位点数量。

BioDolphin是蛋白链—配体实例及结合位点记录，包含的化学对象须按来源查看。未建立脂质类别规则时称“配体结合/接触”，不统一称脂质接触。MPLID原有标签、负标签与距离/confidence保留，不增加来源不存在的脂质ID。

## Basic Info补充分析与处理（2026-09-21）

当前问题不是缺少膜来源，而是蛋白级信息被埋在位点轨道和记录数之后。用户已授权补充现有Basic Info。实际实现及口径以[当前方案](../../plan/protein_overview.md#basic-info膜特征重排2026-09-21追加当前实现)为准。

| 问题 | 本轮处理 | 科学含义边界 |
| --- | --- | --- |
| HTP只能看到记录量，看不到蛋白级结论 | 默认显示来源TM数、reliability、signal区域、方法及约束概况 | 原值展示，缺失不推断为零 |
| 拓扑只在密集序列轨道中出现 | 展开面板内增加按原序列顺序的区域卡片示意，可切换来源 | 标注非比例图，不生成共识 |
| 来源、方法和证据作用混杂 | 数据库→原记录/链→综合/方法/约束/实验结构分类 | 重用证据与benchmark集合不当独立支持 |
| TOPDB文献与PDB埋在XML中 | 解析Exp、Type/Subtype、Ref、pdbRef/Chains、Value | 原区段数量不等于独立实验数量 |
| 只展示已映射来源会遮蔽关联结构对象 | 来源列表保留identity关联对象，显式标记未映射 | 原序列坐标与canonical映射分开 |
| 证据默认平铺导致阅读负担 | 摘要常显、来源集合折叠、单区段详情再次展开 | 数据保留完整，20条分页并可按方法筛选 |

只读抽查：P00533的HTP原记录为EGFR_HUMAN，长度1210；numTm=1、reliability=94.77，综合区段S1–24/O25–645/M646–667/I668–1210，11种方法输出（包含SignalP）、9条TOPDOM约束。71条feature为全部角色的记录总数，不是71个膜区段。P00533关联22个拓扑原序列对象，其中PDBTM对象存在identity已关联但canonical未映射的情况。

TOPDB首条展示证据支持结构类型PDBTM、PMID 26586721、PDB 4uv7/链A；来源Value保留为原记录值，不替代当前canonical坐标。解析失败与未提供证据分别提示。HTP方法与可靠性解释沿用来源定义，背景依据：[UniTmp/HTP论文](https://academic.oup.com/nar/article/52/D1/D572/7327069)、[CCTOP论文](https://academic.oup.com/nar/article/43/W1/W408/2467915)、[TOPDB](https://topdb.unitmp.org/)。

实现入口：`Web/src/api/membrane_topology.py`负责摘要/证据读取，`MembraneTopology.tsx`负责来源与区段展示。未进行新的结构映射、来源采集、膜方向推断或数据库迁移。
