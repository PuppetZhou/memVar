- 导入传输已实际验证null、空字符串、NA、零字符串、字面\N、引号、多行与COPY结束标记文本的往返。

### 运行入口

`python Web/src/build/build_context.py`构建QTL/PPI/HPA；`python Web/src/build/build_context_gtex.py`提取冻结GTEx目标值；`python Web/src/build/finalize_context.py`整合清单；`python Web/src/build/validate_context_projection.py`核对来源重建；`python Web/src/database/import_context.py`导入暂存schema、核对后切换。

资源修复：首次PPI JSON逐字段展开触及8GB内存限制，改为记录内列表投影，并复用已完成的Parquet；不重跑科学映射。导入失败时保留隔离暂存schema及已完成表，依据`postgresql_context_loading.json`恢复，不破坏现用web或web_context。

未决：Tabula汇总口径、PPI未正式发布的界面预测、QTL等位基因mapping继续暂缓。所有测量值保留来源类型；源字符串中的NA/空值没有被擅自转成零，前端按指标类型解析，不按文本排序数值。暂无API/页面或并发负载验收。
