## 筛选、复用和精简

- canonical由protein.default_sequence_id确定，沿用已确认PTM映射。非canonical记录不改挂；未定位记录保留原位置、原文及状态，不上残基轨道。
- 591条蛋白身份歧义记录仍保留candidate_accessions供候选蛋白背景导航，不生成候选位点关系。完整候选序列表保留上游，不导入轨道库。
- PTMD2的103,800条记录保留来源疾病、修饰变化、MutationSite等内容，仍无正式位点连接。本版不建立DNA变异关系。
- UniProt详情和59,838次对应PTM证据通过feature引用恢复，不重复保存完整payload；跨数据集同位点记录不合并。膜feature同名视图保留此前43,014条范围。
- PS证据数据集的URL、Current与原说明只存一次，证据视图恢复逐条关联。不可解析引用仍保留原文。
- JSD验证序列级字段一致后将n_sequences/alignment_scope/homology_status放summary；不改变分数、逐位点质量信息或同源不足状态。
- Pfam沿用本地38.2和--cut_ga；7,710条输入相同序列复用，仅5条增量扫描。228条已处理零命中保留。科学交付见[Pfam专题](../../../../modules/Site-Region/docs/pfam.md)。三套边界均存储，主显示边界尚未指定，不影响本次入库。

## 运行和验收

可重建入口：

```bash
python run.py Site-Region build-pfam --publish
python Web/src/build/build_tables.py
python Web/src/database/import_tables.py
python Web/src/database/validate_import.py
```

Pfam上游重跑需配置新的run_id，不覆盖既有运行；Web按当前表目录替换。输入和版本见Web/config/inputs.yaml，规则见Web/config/tables.yaml。

状态：Parquet构建、PostgreSQL导入、临时schema验证及切换后Basic info兼容性验证均通过；详见[导入报告](../../../data/postgresql_import.json)和[Sequence验证](../../../data/sequence_validation.json)。临时schema完成行数、外键、canonical/残基、端点、证据和查询检查后才事务切换。API、页面、并发负载不在本轮验收范围。

本次导入耗时255.3秒，数据库总大小5,987,284,659字节（约5.99 GB）。Sequence查询测得：PTM_site 1.484 ms、UniProt_features 0.534 ms、JSD_range 0.094 ms、Pfam_hits 0.198 ms。这些是本地单客户端样例，不代表并发性能。

PTM详情视图另恢复mapped_sequence_id/mapped_start/mapped_end：仅对现有明确成功mapping状态，从canonical身份与原坐标取得；逐条来源核对可恢复性通过，未定位仍为空。仅停用证据记录即使已有序列定位也不生成现行site连接。
