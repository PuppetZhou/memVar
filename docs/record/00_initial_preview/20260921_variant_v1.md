# Variant服务构建与导入：20260921_variant_v1

2026-09-21。构建、PostgreSQL导入与验证均已完成。数据库`memvar_web`的`web_variant` schema现为`20260921_variant_v1`，11张业务表、6个普通视图；[导入与验证报告](../../../data/postgresql_variant_import.json)与服务manifest的built_at一致。输入、字段及数量见[服务清单](../../../data/tables/variant/manifest.json)，最终契约见[Variant方案](../../archive/00_initial_preview/plan/variant_tables.md)。

## 本轮实施

五张核心表为variant、variant_consequence、variant_source_record、variant_source_link、variant_frequency；辅助表保留dbSNP等位基因证据、ddG预测/关联/状态、来源字典和58字段字典，共11张业务表。VEP完整选中后果及dbNSFP原数值/状态保留；AlphaGenome三项与两个来源状态按variant_id合并。

后果中的重复DNA坐标从variant取得，预测重复ENST/ENSP从已验证相等的Feature/ENSP取得；不能以去版本stable_id替代带版本ID。ClinVar/COSMIC/gnomAD选中来源记录的全部注释和dbNSFP原数组/类别/机制说明保留为JSONB证据；来源成员和rsID通过关系视图取得。

频率直接读取已发布63字段与缺失状态；ClinVar/COSMIC重叠变异按variant_id共用。ddG既有6,292,698条预测全部符合当前canonical筛选，通过prediction_id连接具体position/ref_aa/alt_aa；原关联表中可恢复的重复字段逐项验证相等后省略，不重算模型。

## 组织与安全替换

Parquet位于Web/data/tables/variant；同一PostgreSQL数据库使用web_variant schema，通过web.protein_gene导航，canonical位点通过web.protein连接。保留此前46张基础/Sequence表及独立context工作。基础Web目录重建保留variant扩展，替换基础schema后重建跨schema查询视图。

新数据先进入临时schema，完整导入、键/关系和查询验证后再切换；失败不替换已发布schema，可按进度恢复。原始来源及正式科研Parquet保持不变。

## 实施中修正

- 预测transcript_id带版本，与VEP Feature相等；不能与transcript_stable_id直接比较。修正核对字段后构建通过，没有改动科学关联。
- 命令行COPY无法安全处理含特殊结束符行的多行原文；改用psycopg 3.3.6 COPY数据通道。真实Arrow JSON扩展类型转换为其字符串存储再传输，JSONB往返一致。
- 大来源详情表按已有Parquet分区四路载入；恢复复用已通过主键、索引及行数核对的其他表，不重复重载。

验证包括全部dbNSFP数值/状态逐值一致、原始来源注释JSON往返、行数及来源键、ddG重复字段可恢复；驱动传输测试覆盖零/null、空串、Unicode、引号、换行和反斜杠。数据库验证已通过，见下文。不声称已实现API、页面或并发负载测试。
