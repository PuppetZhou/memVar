# 2026-09-21：memVar 网站初版交付

2026-09-21 02:31（香港时间）核对。本次交付真实 PostgreSQL 驱动的本地科研数据库初版，完成前后端构建、字段分层及代表性浏览器流程验收。未重新导入数据、修改科研筛选或另建测试数据库。当前实现基线见[初版方案](../../archive/00_initial_preview/plan/website_v1.md)。

## 入口与运行

- 本地页面：<http://127.0.0.1:8000>；默认 EGFR 示例，可搜索其他项目蛋白。
- API 文档：<http://127.0.0.1:8000/docs>；健康检查：`/api/health`。
- 已启动单个 Uvicorn 进程，由相同 8000 端口提供静态前端和 API，无开发 reload。数据库继续使用既有本机 55432 实例。
- 从项目根目录执行 `Web/start-local.sh`。修改前端后先在 `Web/frontend` 执行 `npm run build`；首次准备前端可执行 `Web/start-local.sh --build`，使用已有 package-lock 安装并构建。
- Python 依赖见[requirements-web.txt](../../../requirements-web.txt)，复用现有 Python 环境。跨机器迁移时先安装依赖、准备既有数据库和配置的结构文件；启动入口不会自动导入数据。
- API 使用独立只读身份和一个连接池；凭据文件不加入版本管理。配置与权限验证见[基础接口记录](20260921_api_core_v1.md)。

本次实际执行了 TypeScript/Vite 构建及不带 `--build` 的正式启动入口；没有为了重复验证安装再运行一次 `npm ci`。

## 内容选择与可用功能

| 需求 | 当前实现与证据 |
| --- | --- |
| 基本信息适中，细节展开 | 默认蛋白/基因身份、canonical 长度、FUNCTION 摘录、膜类别及简洁定位；完整原文、isoform、交叉引用、GO/Reactome/Rhea/药理与来源证据按需展开。日期、内部路径、原始大 JSON 不放入科研主视图 |
| 多轨道序列 | Nightingale 共用 canonical 坐标：PTM、Domains/regions（含独立二级结构子轨）、Membrane、Function sites，以及连续 JSD；可按来源、轨道和区间查看，点击位点读取证据 |
| 真实三维结构 | PDBe Molstar 加载本地 AlphaFold PDB，展示预测身份及 pLDDT；逐残基核对模型序列与当前 canonical 后才启用选择定位，保留链/残基号/插入码 |
| 变异筛选及评分分层 | ClinVar/COSMIC/gnomAD 来源和后果类型筛选；主行 CADD/REVEL/SIFT，详情分类展示所选预测字段、来源临床证据、群体频率及 canonical ΔΔG |
| PPI 类型筛选 | 按来源与原始互作类别筛选；详情含参与者、原角色、方法及文献。项目外蛋白使用外链，负证据和非蛋白对象保留 |
| 表达、QTL、疾病独立 | 表达区分正常/癌症/细胞等背景并保留单位；QTL 保留来源组装、组织、表型和统计量；疾病区分基因疾病证据、HPO 表型与 ClinGen 剂量 |
| 可分享查询与适量加载 | 蛋白对象和已应用列表筛选写入 URL；列表每页 10 项，详情按来源和类别展开；切换条件清除旧分页 |
| 简单环境 | 同一个 PostgreSQL、一个后端服务、一个前端构建、一个浏览器会话。没有 Redis、任务队列、第二套测试库或另建 Python 环境 |

本期展示选择由初版自主构建授权落实；此前 Basic info 第 1 题未收到用户答案，不将当前推荐分层记成用户逐项选择。该审查可继续用于后续调整，不改变科研数据本身。

## 实际验证

API 的 SQL、只读权限、对象边界和缺失样例分别见[基础/Sequence](20260921_api_core_v1.md)与[证据接口](20260921_api_evidence_v1.md)。下列浏览器验证复用唯一 `memvar-v1` 会话及真实数据库，桌面 1280×720、窄屏 390×844；不是模拟页面。

| 操作 | 结果 |
| --- | --- |
| EGFR 初始加载 | 八个专题入口可见，五类分页证据列表返回；最终完整加载未出现 JavaScript 异常或本站 HTTP ≥400 响应 |
| 蛋白检索与空结果 | CFTR 搜索进入 P13569；切蛋白不沿用旧位点。无匹配检索显示空结果；A0A075B6H7 显示缺本地模型，其他内容可访问 |
| 变异筛选与分页 | ClinVar＋missense 的 10 条结果全部符合条件；第二页内容改变，详情能展开预测分组、AlphaGenome、群体频率和来源记录 |
| ΔΔG | 浏览器显示真实数值与 kcal/mol；ThermoMPNN 原模型的负稳/正失稳语义从实际处理链和原论文核实，未知模型不套用；数值未翻号或缩放 |
| PPI | IntAct＋direct interaction 筛选结果符合条件，参与者证据窗口可用 |
| 表达 | GTEx 正常表达保留 TPM；切到 cancer 后旧来源清除，显示癌症记录及测量详情 |
| QTL | QTLbase 来源切换可用，详情展示分子表型；极小字符串 P 值不转为 0 |
| 疾病 | HPO 来源过滤可用；详情包含关联表型、Qualifier 与来源证据入口 |
| 序列与结构 | 查找 858 后显示 843–908 区间；L858 联动 AlphaFold chain A residue 858；缩放条实际拖动有效。DeepTMHMM2/UniProt 来源切换保持区间，并清除不再可用的注释来源筛选 |
| 序列下载与边界 | 浏览器 FASTA 下载为 P00533、1,210 aa，858 位为 L；越界搜索显示输入提示；API 越界返回 422 |
| 膜来源详情 | OPM 原坐标依据、带 Å 单位的几何量，MPLID 的 true/false 接触标签、BioDolphin 的配体与编号体系均进入详情；0 与 false 未当作缺失 |
| 响应式与构建 | 窄屏整页宽度未超视口，表格在自身容器内滚动；序列轨道、输入、残基格仍可用；最终 `npm run build` 通过 |

本轮发现并修复的交互问题包括：Nightingale 缩放条保留旧 SVG 宽度、切拓扑来源丢失区间、无效来源筛选留下空轨道、分类变化复用旧 cursor、预测卡片元信息连在一起、缺静态资源错误返回 HTML。验证按这些受影响路径执行，未重复全量科研扫描。

## 当前边界

- 本地可用初版，不宣称完成公网域名/TLS、常驻进程守护、外网发布或并发容量验收。
- 使用已入库范围；PPI 界面预测虽已正式发布，尚未接入本期服务库。KEGG、新版 rSASA、ClinVar 条件关联和待定统计继续按各自计划处理。
- 默认序列轨道仍仅 canonical，不将 MANE 后果自动投到 UniProt canonical；跨来源定位、临床结论和效应值不合并成统一评分。
- 结构模型须本地存在，精确映射失败时不提供位点联动。模型控件已有分片选择，但本轮浏览器定位验收使用 EGFR 单模型，不据此声称全库每个模型都经人工查看。
- 首版有明确的来源详情截选：例如每源膜记录请求上限 50、单组预览 12，变异/疾病来源详情上限 100。页面注明截选，完整正式数据仍留在 PostgreSQL/科研 Parquet；未实现全库下载或自定义批量分析。
