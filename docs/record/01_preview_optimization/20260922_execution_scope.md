# 01阶段执行范围与服务基线

日期：2026-09-22。

## 用户确认与优先级

用户授权开始逐步完成01阶段任务，要求优先处理重要问题。当前只考虑桌面端；手机及390px窄屏适配延后，不作为当前批次完成条件。现行优先级由[01计划](../../plan/01_preview_optimization/README.md#执行优先级)维护：先处理全站数据口径和核心Sequence → Variant → Structure路径，之后推进证据展示、视觉及大数据浏览。

这项范围调整不删除已有响应式代码，也不改变55个问题的科学含义。后续移动适配仍使用原问题和验收描述，不另造一份重复清单。

## 运行核查与公网暂停

- 暂停前，PostgreSQL容器、Uvicorn和ngrok均在运行；ngrok指向本地8000端口。
- 用户随后明确允许暂停公网运行。本轮向ngrok进程发送TERM并核对进程已退出；没有停止PostgreSQL或本地Uvicorn。
- 暂停后`GET /`继续返回HTTP 200；`GET /api/health`返回HTTP 200、`database=PostgreSQL`、`read_only=true`。
- 主文件系统可用空间约2.1 TB；内存约121 GiB、核查时可用约117 GiB，不构成本轮开发资源瓶颈。

## 执行边界

公网暂停后，开发和后端发布不再受零停机约束；本地服务可按实施需要重启。正式替换仍需先完成候选构建、接口健康检查和桌面关键路径验收，不能因无公网访问就直接覆盖可用版本或省略必要验证。恢复公网预览须在对应版本完成验收后单独执行并记录。

## 本轮验证限制

内置浏览器插件存在，但核查时没有可连接的浏览器实例，因此未将视觉或真实点击标为通过。本轮完成了进程、端口、HTTP健康、资源和部署结构核查；桌面端浏览器验收在浏览器实例可用后补做。
