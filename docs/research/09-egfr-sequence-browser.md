# CATVariant EGFR Sequence Browser：交互、配色与动效拆解

访问日期：**2026-09-22（Asia/Shanghai）**。对象：[EGFR → Sequence](https://catvariant.com/genes/EGFR#sequence)，桌面视口 **1280 × 720**。本轮通过真实页面操作、截图、DOM 与 computed style 调研；主要分析序列浏览器，结构视图只调查与它直接关联的状态。页面序列长度为 1,210 aa。本文是对 [FBN1 交互报告](04-interaction.md) 的补充，不把此前的 FBN1 测试当作 EGFR 的验证结果。

**最值得借鉴的是：固定序列坐标，通过 lens 改变观察问题；通过淡化、边框和详情卡逐层集中注意力。** 动效以短颜色过渡为线索，不能仅凭样式定义认定其平滑度。已实测单位置和区间搜索、残基点击、四种 lens 切换、每行 50→25 残基；3D 反向选择、连续动画时序与移动端仍待验证。

## 1. 页面如何组织阅读

![EGFR 默认 Prevalence 与搜索焦点](../../../fig/captures/catvariant/2026-09-22_egfr_01-prevalence.jpg)

**[观察事实]** 白色面板从上至下为：紫色 DNA 圆形图标和标题 → 搜索 → lens 与分组条件 → 指标说明 → 图例 → 带行号的序列 → 聚焦状态及密度控件。右上角黑色链接图标按钮标为 `Synced with 3D viewer`。顶部还有独立的章节导航。[E019](evidence.md#e019)

**[分析解释]** 这是一种“先选问题，再读数据”的组织方式。搜索负责定位对象；lens 负责解释背景色；图例负责解释阈值；残基负责进入详情。DNA、放大镜、眼睛、链接等图标辅助识别功能，核心动作仍保留文字，读者不必猜图标含义。

**局限与借鉴：** 工具栏、说明和图例占用较多纵向空间，720px 高视口只能看到部分序列。适合密集探索，但应提供紧凑说明模式，把当前指标名、聚合方式、缺失值解释始终保留。不要直接隐藏决定颜色含义的文字。

## 2. 实际操作与状态变化

| 操作及复现步骤 | 本轮实际结果 | 可借鉴价值与限制 |
| --- | --- | --- |
| 在序列搜索输入 `858` | L858 的可访问名称增加 `search match 858`；其 opacity 为 1，非匹配样本为 0.42；出现清除按钮 | 保留序列上下文，适合查找单位置；本轮未确认自动滚动到命中位置 |
| 将输入改为 `790-795` | 790–795 六个残基均被标记命中、保留 opacity 1，其他样本降至 0.42 | 可以辨认连续片段；本轮未验证逗号列表、序列片段、变异标签和异常输入 |
| 点击清除搜索，再点击 N56 | 出现 N56/ASN、Glycosylation、3 个变异的浮层；序列出现 N56 周围 8.0 Å、8 个高亮残基、结构 1NQL 和 Unfocus residue 控件 | 从一级序列位置连接到空间邻域；只有这一次邻域状态得到验证，未核对邻居原子距离算法 |
| 切换四种 lens | 激活按钮、说明、图例和残基颜色随之改变；N56 聚焦仍保留 | 数据视角和所选对象可分别保留；截图中较淡的颜色同时受聚焦影响 |
| 将每行残基数从 50 改为 25 | 控件值变为 25；残基内联尺寸从 23×23px 变为 46×46px，字体从 14.26px 变为 28.52px；截图行号步长为 25 | 是重新排布与放大，而非仅缩放整张图片；连续拖动的流畅度未测 |

以上为 **[观察事实]**，来源分别为 [E020](evidence.md#e020)、[E021](evidence.md#e021)、[E022](evidence.md#e022)、[E023](evidence.md#e023)。尺寸来自当时 DOM 内联样式，不是通用设计常量。

### 2.1 搜索强调与聚焦强调要分开

**[观察事实]** 搜索命中采用琥珀背景和浅阴影；区间命中的原结构域橙色上下边框仍存在。点击 N56 后，选中残基出现明显黑色外框，非邻域样本 opacity 为 **0.25**，比搜索的 **0.42** 更淡。搜索命中阴影为 `0 6px 16px rgba(245,158,11,0.16)`。[E020](evidence.md#e020)、[E021](evidence.md#e021)

**[分析解释]** 搜索是“我要找哪里”，邻域聚焦是“我要看它周围什么”。两者都保留完整序列，但缩小视觉注意范围。不同透明度表现强调强度，不过缺少显眼的状态说明时，读者可能把淡色误认为低分或缺失数据。

**[实现建议]** 在序列上方显示独立状态条，例如“搜索：790–795 · 6 个命中”和“结构邻域：N56 · 8 Å”，各自提供清除。用外框表示命中，用底色保留数据值，减少搜索覆盖原指标颜色的代价。

### 2.2 从残基到变异卡片

![N56 位点浮层与邻域聚焦](../../../fig/captures/catvariant/2026-09-22_egfr_04-residue-56.jpg)

**[观察事实]** N56 浮层顶部显示位置、三字母氨基酸名、修饰类型、变异数；下面为 N56I、N56S、N56Y 三张紧凑卡片，包含变异类型与星级。底部给出继续查看详情和结构定位提示。会话也实际出现 N56I 详情模态框并完成关闭，但该次打开发生在工具定位偏移期间，不能把它作为经过控制的“准确点击 N56I”复现测试。[E021](evidence.md#e021)

**[分析解释]** 单字母格子承载导航；浮层提供位点摘要；更深的详情承载长文。这能避免在序列本体塞入全部证据。代价是浮层会遮挡临近序列，星级也容易被误读为临床结论。

**[实现建议]** 保留“位置 → 位点摘要 → 单变异详情”层次；浮层避开锚点和当前行，提供固定/关闭操作；星级必须有文字名称与依据。鼠标悬停预览、点击固定、键盘进入详情的规则应一致。本轮只确认实际出现的卡片和点击状态，未独立验证纯 hover 的触发延迟、离开关闭策略。

## 3. 四种 lens：颜色必须跟着问题解释

**[观察事实]** 四个入口均能切换；带 `+ more` 的按钮在本轮点击后出现子菜单。页面提示 hover 可看更多选项，但纯悬停路径未单独测试。[E022](evidence.md#e022)

| Lens | 页面解释及图例 | 本轮验证与理解边界 |
| --- | --- | --- |
| Prevalence | Variant count；也提供最高、中位、最低 allele frequency | 实际选回 Variant count；计数图例为 No variants、1、≤4、≤5、≤6、≤8。没有验证 AF 子模式的数据更新 |
| Predicted Functional Impact | 默认 Worst-case；子菜单还有 Average / Best-case；图例为无预测数据、Very Low <0.30、Low 0.30–0.49、Moderate 0.50–0.69、High 0.70–0.84、Very High ≥0.85 | 切换和菜单已见；这些是页面给出的优先级分档，未验证聚合计算。Average 菜单称 Weighted average，具体权重未知 |
| Trafficking/Activity Impact | No assay data、Low <15、Moderate 15–40、High 40–70、Very high ≥70 | 页面解释为 MAVE 实验影响；未核实该分值归一化方法与跨实验可比性，不能当作百分比 |
| Variant Hotspot | 子来源为 Trafficking/activity impact、REVEL、AlphaMissense；当前为 Cluster 1A（5 aa）、2A（8 aa） | 颜色表达簇身份，不表示从低到高；当前文字解释使用 AlphaMissense，未逐一切换来源和验证3D颜色同步 |

表内有关指标来源、算法与含义的内容是**页面说明的转述**，不是本轮对算法正确性的背书。预测、实验、群体频率和临床分类应保持分离。

![预测影响：聚合模式菜单](../../../fig/captures/catvariant/2026-09-22_egfr_06-impact.jpg)

**[分析解释]** 不改变序列位置，仅改变底色和图例，使读者能够在同一坐标系里比较不同问题。子菜单把“选择指标”和“选择聚合方法”分层，减少常驻按钮数量。缺点是隐藏选项的发现成本较高，长说明可能把序列往下挤。

**[实现建议]** 当前聚合方式应常驻显示，例如“预测影响 · 最大值”，而不是只靠展开菜单确认。对于实验分值，应额外提供 assay 名称、单位/转换方式、覆盖范围和缺失值说明。热点必须使用分类色板，数量或分数优先使用有序色板。

## 4. 配色与细节：拆成独立的视觉通道

### 4.1 实测 Prevalence 色板

下表将截图中的图例与默认残基 computed style 对照；HEX 由实测 RGB 换算。阈值仅属于此次 EGFR 页面，不推广为全站固定分箱。[E019](evidence.md#e019)

| 当前图例 | 颜色 | 视觉角色 |
| --- | --- | --- |
| No variants | `#FFFFFF` | 保留空白底 |
| 1 variant | `#E5E7EB` | 浅灰 |
| ≤4 variants | `#86EFAC` | 浅绿 |
| ≤5 variants | `#93C5FD` | 浅蓝 |
| ≤6 variants | `#FDE68A` | 浅黄 |
| ≤8 variants | `#FCA5A5` | 浅红 |

**[分析解释]** 浅底配黑字使氨基酸仍可辨认，彩色块能快速提示分布。但绿→蓝→黄→红不是单一明度顺序，读者必须记住图例；“≤”标签单独看也会重叠，需要按有序分档理解。

**[实现建议]** 自建网站不必复制这套色板。数量用一套连续明度色阶；区间写全，例如“2–4、5、6、7–8”，但必须根据实际分箱算法生成。把“没有变异记录”“没有预测数据”“没有实验覆盖”作为不同语义，不能统一当作零。

### 4.2 一个残基格子同时承担哪些视觉信息

| 通道 | 观察到的用途 | 借鉴与代价 |
| --- | --- | --- |
| 字母与行号 | 等宽粗体单字母，左侧行起始坐标 | 能按坐标阅读；50/行时单格23px，适合鼠标精细操作，触屏仍需测试 |
| 背景 | 当前 lens 的值或簇；搜索命中也会覆盖背景 | 高信息密度，但应清楚规定状态优先级 |
| 上下边线 | 结构域橙色、跨膜紫色，图例另有 Regions 绿色 | 不挤占背景色；EGFR实际 Regions 为0，不能说本例验证了区域轨道 |
| PTM 小圆点 | 字母上方的彩色修饰标记；N56浮层确认Glycosylation | 保留底色；点小且颜色多，需文字 tooltip 辅助 |
| 外框 | 选中N56的黑色框 | 比单靠换底色更适合表达选中 |
| 透明度 | 搜索非命中0.42；邻域外样本0.25 | 突出相关对象，但降低非重点文字可读性 |
| 阴影/圆角 | 搜索命中浅阴影、残基小圆角、浮层圆角与阴影 | 建立层级；不应让每个普通残基都带强投影 |

**[观察事实]** EGFR Protein kinase 标注为712–979，跨膜段646–668；L858等结构域样本上下边线为 **4px、rgb(234,88,12)**。这些是页面显示的规范蛋白位置，不是基因组坐标；本轮未核查异构体和结构编号映射表。[E019](evidence.md#e019)、[E020](evidence.md#e020)

## 5. 动效：可以确认什么，不能确认什么

### 5.1 已采集的动效证据

**[观察事实：样式]** 残基 computed style 包含颜色相关的 **200ms** transition，缓动为 `cubic-bezier(0.4, 0, 0.2, 1)`，属性包含 color、background-color、border-color、text-decoration-color、fill、stroke。DOM 类名也包含 `transition-colors duration-200` 与 `hover:bg-yellow-100`。样本没有持续循环的 CSS animation。[E024](evidence.md#e024)

**[观察事实：状态终点]** 已看到 lens 改变后的颜色、菜单展开、N56浮层、邻域淡化和25/行的大字号布局。没有采集连续视频或帧时序，因此不能写“已测得200ms完成”“60fps”“弹簧动画”或“平滑自动飞入3D”。

| 效果 | 本轮证据强度 | 不能扩大为的结论 |
| --- | --- | --- |
| 残基颜色过渡 | 当前元素确有200ms颜色transition，前后颜色改变 | 不能证明每次交互都执行完整过渡 |
| 非匹配淡化 | opacity终值0.42/0.25已测 | 当前transition列表不含opacity，不能称其为200ms淡入淡出 |
| 缩放/换行 | 50→25后格子和字体翻倍，布局重排已见 | 不知道尺寸变化是否有JS动画或掉帧 |
| 菜单/详情浮层 | 展开后的界面已见 | 进入/退出延迟、位移和缓动未知 |
| 3D镜头定位 | 页面有同步说明，N56聚焦状态已出现 | 未验证镜头轨迹、自动旋转、反向点击同步 |
| 页面背景装饰 | 截图有低对比度网格与散落字母 | 静态截图不能证明字母在漂浮 |

### 5.2 我们可以采用的动效规范

以下均为 **[实现建议]**，不代表 CATVariant 原实现：

- 颜色切换使用150–200ms短过渡，目的在于维持“同一残基换了指标”的连续感；无需动画整行位移。
- 搜索命中保留稳定外框；若淡化需过渡，应显式写opacity，避免把颜色transition当作已经覆盖它。
- 浮层可用轻微透明度变化，不做大幅弹跳；鼠标跨进浮层时保持可操作，键盘焦点不能随动画消失。
- 每行数量变化优先保持当前选中残基可见，再考虑过渡；长序列重新换行时不宜逐格飞入。
- 结构镜头仅在明确的“定位到结构”操作后移动，提供停止/重置；不要让每次悬停都改变视角。
- 尊重减少动态效果偏好；关闭非必要动画后，匹配、选中与加载状态仍然清楚。

## 6. 如何独立实现，而不是复制整页

**[观察事实]** 此页序列使用带 `data-residue-position`、`role="button"`、`tabindex="0"`、`aria-label` 的 DOM单元；本轮默认采样得到1,210个残基元素。因此不需要把这一模块理解为必须采用Canvas/WebGL。但这不能推出原站所有规模下的渲染或性能策略。[E019](evidence.md#e019)

**[实现建议]** 保持数据、颜色和交互状态独立。最低限度的状态与职责如下：

| 模块 | 输入与输出 | 难点/验收 |
| --- | --- | --- |
| SequenceGrid | sequence、规范位置、rowsize → 残基格子与位置事件 | 放大后序列顺序与位置不能改变；键盘可操作 |
| LensControls + Legend | lens、aggregation、来源、阈值 → 颜色函数与说明 | 一次切换同时更新图例、单位和缺失值标签 |
| SearchState | query → matchedPositions、解析错误 | `790-795`恰好命中6格；不修改原始序列 |
| ResiduePopover | position → variants、PTMs、来源 | 浮层可关闭、可进入详情，不遮挡所选残基 |
| StructureAdapter | protein position ↔ model/chain/residue mapping | 无映射时明确提示；切换模型后重新计算覆盖 |
| FocusState | selectedPosition、neighborRadius、neighborPositions | 取消聚焦只清理该状态，不意外清除搜索或lens |

建议状态结构：

```text
lens = { metric, aggregation, evidenceSource, population, sex }
query = { rawText, matchedPositions, validationMessage }
selection = { canonicalPosition, variantId }
structure = { modelId, chainId, mappedPositions, neighborRadiusAngstrom }
layout = { residuesPerRow }
```

所有分值保留来源和缺失状态；结构映射需处理缺失坐标、链、插入码、异构体编号，不应只用一个整数假定两边位置相同。3D空间近邻需要坐标或已验证的邻接数据；本轮没有证明原站如何计算它。

## 7. 学习优先级与总结

| 优先级 | 建议借鉴 | 成本及依据 | 可验收行为 |
| --- | --- | --- | --- |
| P0 | 固定序列坐标 + lens/图例同步 | 中：需要规范数据契约和缺失值规则 | 换指标不换序列；颜色可解释 |
| P0 | 搜索与选中分离 | 中：需处理状态叠加与焦点 | 清除搜索不误清选中；范围解析准确 |
| P0 | 残基摘要渐进进入变异详情 | 中：浮层定位和键盘交互需细调 | 可读、可关闭、可继续操作 |
| P1 | 密度滑块与短颜色过渡 | 低至中：布局重排与阅读位置保持 | 50→25后坐标连续、选中对象可找回 |
| P1 | 序列—结构邻域联动 | 高：结构映射、覆盖、空间距离与状态同步 | 无坐标能解释，有坐标能定位，切模型不串号 |
| P2 | 装饰背景与更多视觉效果 | 低至中：收益小于核心阅读问题 | 不降低对比度，不抢夺交互注意力 |

最值得学习的四点是：**固定坐标、多维lens、渐进详情、上下文淡化**。最需要改进的是：**有序数值的色阶、当前状态的可见解释、聚合方式标识，以及浮层和放大后的定位体验**。以上是基于本例的设计判断，不是跨网站性能或易用性排名。
